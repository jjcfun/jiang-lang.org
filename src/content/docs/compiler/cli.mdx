---
title: Compiler CLI
description: Jiang compiler command-line interface.
---

`jiang` compiles Jiang source files. The current compiler can emit LLVM IR, object files, or link an executable through the host C compiler.
Release packages retain `jiangc` as a compatibility link for existing scripts; new commands should use `jiang`.

## Version and Help

```bash
jiang --version
jiang --help
```

`--version` prints the Jiang compiler version, host target, and LLVM version.

## Check Only

```bash
jiang --check tests/samples/minimal.jiang
```

This parses, resolves, and type checks the program without emitting LLVM IR, an object file, or an executable.

## Emit LLVM IR

```bash
jiang --emit-llvm tests/samples/minimal.jiang
```

By default, LLVM IR is written to standard output. Use `-o` to write it to a file:

```bash
jiang --emit-llvm -o minimal.ll tests/samples/minimal.jiang
```

## Emit an Object File

```bash
jiang --emit-obj -o minimal.o tests/samples/minimal.jiang
```

This stops after object generation and does not link an executable.

## Link an Executable

Without an explicit `--emit-*` mode, `jiang` creates a temporary object file and asks the host `cc` to link an executable:

```bash
jiang -o minimal tests/samples/minimal.jiang
```

Then run:

```bash
./minimal
echo $?
```

## Debug and Release Modes

`jiang` defaults to debug mode:

```bash
jiang --mode debug -o main main.jiang
```

Release mode enables LLVM optimization:

```bash
jiang --mode release -o app .
```

## Targets

Use `--target` for LLVM IR or object output:

```bash
jiang --target x86_64-unknown-linux-gnu --emit-obj -o main.o main.jiang
```

Hosted executable linking is native-toolchain only. Release packages support macOS arm64 and Linux
x86_64; Linux hosted programs use the system libc.
Linux aarch64, Wasm, WASI, and Windows targets currently have narrower or experimental output
boundaries, and Linux no-libc executable support is not yet available.

## Linker Options

Use `--linker` to select the program used for final linking:

```bash
jiang --linker /usr/bin/cc -o main main.jiang
```

Pass extra linker arguments with repeated `--link-arg` options:

```bash
jiang -o main --link-arg -lm main.jiang
```

## Runtime Boundary

Hosted builds use the target host's C runtime and native linker toolchain. Release compilers include
the LLVM libraries used by `jiang`, so running a packaged compiler does not require a separate
`libLLVM` or `liblld` installation.

## Generation

Run the package root generator or select a configured alias:

```bash
jiang generate .
jiang generate . --name models -o build/models
```

See [reflection and generation](/language/generation/) for entry contracts, configuration, output replacement and caching.
