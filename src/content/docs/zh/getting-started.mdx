本指南假设 `jiang` 已经安装好，并且可以从 `PATH` 中直接运行。如果还没有，请先阅读[安装](/zh/install/)。

## 编写程序

创建 `hello.jiang`：

```c
Int add(Int a, Int b) {
    return a + b;
}

Int main() {
    print(add(40, 2));
    return 0;
}
```

Jiang 函数一定有返回类型。程序入口是 `main`；`print` 输出 `42` 并换行，`return 0` 表示成功退出。

## 编译为可执行文件

```bash
jiang -o hello hello.jiang
```

运行程序：

```bash
./hello
echo $?
```

程序输出 `42`，随后 `echo $?` 显示退出码 `0`。

安装 [VS Code 扩展](/zh/compiler/editor/)后，可以使用补全、悬停文档和定义跳转。

## 查看 LLVM IR

语言开发阶段，经常需要查看生成的 LLVM IR：

```bash
jiang --emit-llvm hello.jiang
```

使用 `-o` 可以写入文件：

```bash
jiang --emit-llvm -o hello.ll hello.jiang
```

## Jiang 代码的基本形态

Jiang 源文件以声明为核心。一个小文件通常包含类型声明、函数和 `main` 函数：

```c
struct Pair {
    Int left;
    Int right;
}

Int sum_pair(Pair pair) {
    return pair.left + pair.right;
}

Int main() {
    Pair pair = Pair(left = 20, right = 22);
    return sum_pair(pair);
}
```
