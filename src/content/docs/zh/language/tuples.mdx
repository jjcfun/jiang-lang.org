元组用于将多个值组合在一起。Jiang 的元组类型写作 `(T1, T2, ...)`。

## 多元组

```c
// 函数通过元组返回多个值
(Int, Int) foo(Int a, Int b) {
  return (a * a, b * 2);
}

// 接收元组返回值
_ result = foo(10, 200);
print("result0 = %d", result[0]);  // 输出：100
print("result1 = %d", result[1]);  // 输出：400

// 解构元组
(_ a, _ b) = foo(10, 200);
print("x = %d, y = %d", a, b);  // 输出：a = 100, b = 200
```

解构时可以指定可变性：

```c
(_ x, _ y!) = foo(10, 200);
y += 100;
print("x = %d, y = %d", x, y);  // 输出：x = 100, y = 500
```

括号是独立解构的语法入口，即使只有一个 binding 也要保留。by-value binding 必须保留
类型位置；借用 binding 可以省略：

```c
(Int left, _ right) = pair;
(ref borrowed) = value;
(Int[_] first, _[3] second) = arrays;
```

Tuple pattern 在 `is`、`switch`、union payload 和 optional payload 中使用同一套递归形状。
variant 直接接收 payload 的一层 Tuple：

```c
if node is .pair(left, right) { }
if node is .nested((left, right), tail) { }
if maybe_pair is .some(left, right) { }
```

## 一元组

一元组 `(T)` 与它的元素类型 `T` 等价，占用内存空间也一致：

```c
// 以下两个函数签名等价
(Int) add(Int a, Int b);
Int add(Int a, Int b);

// 以下两种语法也等价
(Int x!) = add(1, 2);
Int x! = add(1, 2);
```

因此 `(ref value) = source;` 会直接借用 `source`，不会额外投影索引 `0`。

## 单元类型

`()` 表示单元类型。单元值不占用内存空间，用于表达“无意义返回值”：

```c
() hello() {
  print("Hello World!");
  return ();
}
```

单元类型可以像普通类型一样作为值、参数、局部变量和字段使用。

## for 循环中的解构

`for-in` 的绑定位置只接受不可失败的绑定模式。遍历元组序列时，先绑定元素，再在循环体内解构：

```c
(Int, Int)[_] pairs = [(1, 2), (3, 4)];

for pair in pairs {
    (_ a, _ b) = pair;
    print("a=%d, b=%d", a, b);
}
```
