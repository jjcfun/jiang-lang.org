`extern` 声明用于调用外部符号，例如 C 库函数或系统接口。使用外部函数接口时，要自己确认参数类型、内存布局和资源释放方式与外部接口一致。

## 外部声明块

外部函数和全局变量可以写在 `extern { ... }` 代码块中：

```c
extern {
    public Int puts(UInt8* text);
    public Int open(UInt8* path, Int options);
    public Int errno;
}
```

也可以写单条声明：

```c
extern public Int puts(UInt8* text);
public extern Int errno;
```

顶层 `extern` 和 `public` 都是声明修饰符。`public` 表示这个外部符号声明也作为当前模块公开接口对外可见。

## C 字符串

C 接口使用 `UInt8*` 表示字符串。字符串字面量传入这种上下文时，会生成以 `\0` 结尾的
只读全局数据：

```c
extern public Int puts(UInt8* text);

puts("hello from Jiang");
```

借用的哨兵字符串视图使用 `UInt8[:0]&`。C 接口需要 raw pointer 时使用
`$.ptr()`；Jiang 代码需要把非字面量 sentinel 视图当作普通字节切片时，显式写
`view.slice()` 或 `view$.as(UInt8[]&)`：

```c
UInt8[:0]& view = "hello";
unsafe {
    puts(view$.ptr());
}

UInt8[]& bytes = view.slice();
```

如果 C 接口需要指针加长度，直接建模成指针参数和长度参数：

```c
extern public Int write(Int fd, UInt8* buf, Int count);
```

## 裸指针

`T*` 主要用于外部函数边界、二进制接口和低层能力场景。它不表达所有权，不参与自动析构，
也不默认自动解引用。

```c
Int value = 42;
Int* raw = unsafe {
    value$.ptr()
};
Int copied = raw$.get();
```

写入单对象裸指针指向的目标需要被指向值顶层可变：

```c
Int value! = 0;
Int*! raw = unsafe {
    value$.mut_ptr()
};
raw$.set(42);
```

## 裸 buffer 指针

`T*` 同时是 C buffer 参数使用的无长度裸连续内存 view：

```c
extern Int read(Int fd, UInt8*! buf, Int count);
```

raw pointer 不携带长度，因此下标访问属于 `unsafe`。`T*` 可按下标读取，`T*!` 还可写入。
Jiang 代码需要长度 view 时优先使用 `T[]&` 或 `{ ptr, len }` 风格的 `struct`。
`T[*]` 和 `T[*:S]` 已经移除。

## 资源边界

外部接口返回的内存是否需要释放、使用哪个分配器释放、是否允许别名写入，都不由 `extern` 声明自动表达。把这类资源包装成 Jiang `struct` 时，建议在包装类型中明确：

- 哪个字段拥有资源。
- 哪个字段只是视图或引用。
- `deinit` 如何释放资源。
- 资源包装类型不要实现 `Copyable`，让普通按值使用执行 move。

```c
struct CBuffer {
    UInt8*! data;
    Int length;

    deinit(self) {
        unsafe {
            self.data$.dealloc();
        }
        return ();
    }
}
```
