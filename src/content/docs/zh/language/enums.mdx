Jiang 使用 `enum` 表示一组固定的具名 case。case 也可以携带值，此时 enum 就是一个
代数数据类型。

## 枚举

`enum` 成员按命名值使用：

```c
enum Mode {
    read,
    write,
}

Mode mode = Mode.read;
Mode other = .write; // 目标类型已知时可省略类型名
```

成员可以指定整数值：

```c
enum Priority {
    low = 1,
    medium,
    high,
}
```

`enum` case 的整数值默认使用 `Int32`。没有显式指定值的 case 会从前一个 case 继续递增。

需要固定存储表示时，可以写 `enum [UInt8]` 或其他整数类型：

```c
enum [UInt8] ByteTag {
    block = 1,
    item,
}

UInt8 tag = UInt8(ByteTag.block);
```

enum 值使用目标整数类型的构造表达式转换；case 不提供 `.value` 成员：

```c
Int value = Int(Mode.read);
```

## Payload enum

payload enum 是带标签的安全代数数据类型，不是 C 风格的无标签裸联合。

```c
enum Outcome<T, E> {
    ok(T),
    err(E),
}

Outcome<Int, ParseErr> a = Outcome.ok(42);
Outcome<Int, ParseErr> b = .err(ParseErr.bad);
```

携带值可以是普通类型，例如 `struct`、Tuple、数组、slice、`Fn<...>`、`T^`、`T&`、`T*`、
可选类型，以及其他 payload enum。

一个 case 可以携带多个值。为这些位置命名后，文档和 pattern 绑定会更清晰：

```c
enum Value {
    none,
    int_value(Int),
    pair(Int left, Bool right),
}
```

payload case 也可以显式指定整数类型和整数值：

```c
enum [UInt8] WireValue {
    none = 1,
    int_value(Int) = 7,
}

UInt8 tag = UInt8(WireValue.int_value(42));
```

case 必须写在方法和嵌套类型之前。enum 同时定义这些成员时，用 `;` 将 case 与成员分开：

```c
enum Value {
    none,
    int_value(Int);

    Bool has_value(self) {
        return self is .int_value(_);
    }
}
```

payload 遵循普通 ownership 规则：move enum 会 move 当前 case 的 payload，borrow payload 不会
move 它，析构 enum 时也只析构当前 case 的 payload。

## `is` 匹配

`is` 用于模式匹配。匹配 payload enum case 时可以解构携带值：

```c
if value is .int_value(_ n) {
    print(n);
} else {
    print(0);
}
```

绑定可以显式写 `_`；需要可变绑定时，把 `!` 写在名字后：

```c
if value is .int_value(_ n!) {
    n = n + 1;
}
```

使用 `ref name` 可以借用 enum payload，而不是按值绑定 payload。省略的类型位表示 `_`；
需要显式 type pattern 时仍可写 `ref T name`：

```c
enum Node {
    pair(Int, Int),
    empty,
}

Int read_ref(Int& value) {
    value$.get()
}

Int first(Node node) {
    if node is .pair(ref left, _) {
        return read_ref(left);
    }
    return 0;
}
```

当承载值较大、不可复制，或者只想检查而不想转移承载值时，应使用 `ref` 绑定。
pattern 中的 `ref! Int value` 会创建 unique mutable `Int&!` borrow。如果结果 reference binding
本身需要重新赋值，写成 `ref Int value!` 或 `ref! Int value!`。

可选值使用 `.some(...)` / `.none` 模式：

```c
if maybe is .some(item) {
    print(item);
} else {
    print(0);
}
```

## `switch` 匹配

`switch` 按模式分支匹配。处理 `enum` 和可选值时，建议覆盖所有情况；需要兜底时使用 `else`。

```c
Int code = switch mode {
    .read => 1,
    .write => 2,
}
```

处理 enum payload：

```c
Int result = switch value {
    .int_value(_ n) => n,
    .code(_ code) => code,
    .float_value(_) => 0,
    .text(_ bytes) => bytes.length,
}
```

借用 enum payload 时使用同样的 `ref` 子模式：

```c
Int result = switch node {
    .pair(ref Int left, _) => read_ref(left),
    .empty => 0,
}
```

处理可选值：

```c
Int value = switch maybe {
    .some(item) => item,
    .none => 0,
}
```

## 模式规则

当前 `is` 和 `switch` 分支根只接受：

- 可选值模式：`.some(item)` / `.none`。
- 变体模式：`.name(...)` 或 `Type.name(...)`。
- Tuple 模式：例如 `(left, right)`。
- 字面量模式：例如 `null`、整数、字符、布尔值。

绑定和通配符只作为子模式使用。Tuple payload 直接传给 variant，因此 `(Int, Int)` payload
写作 `.pair(left, right)`；只有嵌套 Tuple 保留括号，例如 `.nested((left, right), tail)`。
