## Struct

`struct` 是名义类型。即使两个结构体字段完全相同，它们也是不同类型。

```c
struct Point {
    Int x;
    Int y;
}

struct Offset {
    Int x, y;
}
```

同类型多字段声明只是语法糖，`Int x, y;` 等价于分别声明 `Int x;` 和 `Int y;`。

## 布局选项

结构体布局选项写在 `struct` 后：

```c
struct [packed, align: 8] Packet {
    UInt8 tag;
    UInt32 value;
}
```

`packed` 表示字段之间不按字段自然对齐插入填充。`align: N` 表示结构体整体对齐至少为 `N`，
并且 `N` 必须是 2 的幂。选项顺序无关，`struct [align: 8, packed]` 与
`struct [packed, align: 8]` 等价；同一个选项重复出现会报错。

## 默认构造

没有自定义 `init` 的 `struct` 可以使用编译器提供的默认构造。默认构造把字段名作为
必填参数标签：

```c
Point point = Point(x: 0, y: 0);
Point^ heap_point = new Point(x: 100, y: 200);
```

默认构造不接受位置参数：

```c
Point point = Point(0, 0); // 编译错误
```

字段可以声明默认值。带默认值的字段在默认构造调用中可以省略：

```c
struct Window {
    Int width;
    Int height = 600;
    Bool visible = true;
}

Window window = Window(width: 800);
```

如果上下文已经提供期望类型，可以用 `.(...)` 省略类型名：

```c
Window make_window() {
    return .(width: 1024, visible: false);
}
```

expected type 是 pointee 类型时，owning pointer 可以自动解引用；字段访问也会自动穿过 `T^`：

```c
print("x=%d y=%d", heap_point.x, heap_point.y);
```

## 字段可变性

字段只在访问路径和字段声明都可写时才能写入。不可变绑定、shared `T&` 或其他不具备写能力的
访问路径会冻结可达字段：

```c
struct User {
    Int id;
    Int age!;
    UInt8[]&? nick_name;
}

User user! = User(id: 123, age: 18)
user.age = user.age + 1;
// user.id = 200; // 编译错误：字段自身不可变

User& readonly = user$.ref();
// readonly.age = 20; // 编译错误：readonly outer borrow
```

如果字段有默认值，构造时可以省略对应字段。

## `init`

`init` 是 `struct` 的构造器入口。它不声明返回类型，并把正在初始化的目标显式写成
第一个 `self` 参数：

```c
struct Point {
    Int x;
    Int y;

    init(self, Int x, Int y) {
        self.x = x;
        self.y = y;
        return ();
    }

    init(self, Int value) {
        self.x = value;
        self.y = value;
        return ();
    }
}

Point p1 = Point(1, 2);
Point p2 = Point(3);
Point^ p3 = new Point(4, 5);
```

规则：

- `init` 不声明返回类型，第一个 `self` 参数表示初始化目标，调用点不传这个参数。
- 可定义多个 `init`，按参数数量、参数标签和类型重载。
- 自定义 `init` 参数遵循普通函数参数规则，包括命名参数和参数默认值。
- 只要类型定义了 `init`，就不再使用编译器提供的默认字段构造。
- `init` 可以写可见性修饰，例如 `public init(self, ...)`。
- `init` 只能通过 `Type(...)` 或 `new Type(...)` 调用，不作为普通函数值暴露。

命名构造器写作 `init name(self, ...)`，并继续使用 value 或 heap 构造语法：

```c
struct Point {
    Int x;
    Int y;

    init origin(self) {
        self.x = 0;
        self.y = 0;
        return ();
    }
}

Point value = Point.origin();
Point^ owned = new Point.origin();
```

命名与未命名 `init` 属于不同的重载集合。命名 `init` 仍是构造器入口，不是普通函数值。

## `deinit`

`deinit` 是 `struct` 的析构入口。它由作用域退出、拥有所有权的指针析构和拥有所有权的字段析构触发；`ptr$.dealloc()` 是低层释放操作，不作为普通析构入口使用。

```c
struct Buffer {
    UInt8* data;

    deinit(self) {
        unsafe {
            self.data$.dealloc();
        }
        return ();
    }
}
```

如果 `struct` 有 `T^` 字段，离开生命周期时这些拥有所有权的字段会被自动释放。若结构体同时定义了自定义 `deinit`，会先执行自定义 `deinit`，再按字段声明逆序释放拥有所有权的字段。

## 方法

结构体函数把 receiver 显式写在参数列表首位时是实例方法；不带 receiver 时是关联函数：

```c
struct User {
    Int id;

    Int zero() {
        return 0;
    }

    Int value(self) {
        return self.id;
    }
}

Int a = User.zero();
User u = User(id: 42)
Int b = u.value();
```

receiver 简写 `self` 是 readonly `Self&`。需要修改可写字段时，显式声明 `Self&! self`；
调用会在需要时建立唯一可变重借用。

## 局部声明

局部变量声明一次只绑定一个名字。需要多个局部变量时，写成多条声明：

```c
Int a = 1;
Int b = 2;
Int c = 3;
```
