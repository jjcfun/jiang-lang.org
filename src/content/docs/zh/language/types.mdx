Jiang 类型按“从左到右、从里到外”的方式阅读。每个类型后缀都会包裹它左侧已经形成的类型。

## 基本类型

常见基本类型包括：

```c
Bool flag = true;
Int count = -123;
UInt size = 123;
UInt8 byte = 255;
Int16 small = -45;
Float value = 12.3;
Double precise = 132.54;
Char ch = 'a';
```

`Int` 和 `UInt` 是指针宽度整数。需要固定 ABI、文件格式或网络协议布局时，使用 `Int8`、`Int16`、`Int32`、`Int64` 或 `UInt8`、`UInt16`、`UInt32`、`UInt64`。

`enum` 的 discriminant 默认使用 `Int32` 存储；只有显式声明其他整数表示时才会改变。

`Void` 是零大小类型，用于表示函数没有有意义的返回数据；它的唯一值是 `()`。

字符串字面量按 UTF-8 字节序列处理。默认借用视图类型是 `UInt8[:0]&`，因此编译器可以在
C 风格边界暴露以 0 结尾的数据，同时把切片长度和哨兵字节分开处理。

```c
UInt8[_] bytes = "jiang";
UInt8[:0]& view = "jiang";
```

字符串字面量在期望类型是普通 `UInt8[]&` 的位置仍可以直接赋值。对于非字面量的
哨兵切片，需要用 `slice()` 或强制转换到 `UInt8[]&` 显式转换：

```c
UInt8[:0]& c_view = "jiang";
UInt8[]& plain = c_view.slice();
UInt8[]& forced = c_view$.as(UInt8[]&);
```

## 类型后缀

类型后缀越靠右，包裹范围越大：

```c
Int[2][3] matrix;
Int?[2][3] nullable_items;
Int?[2]?[3] nullable_rows;
```

可以把 `Int[2][3]` 读成：

1. `Int`
2. `Int[2]`：两个 `Int` 的数组
3. `Int[2][3]`：三个 `Int[2]` 的数组

常见后缀如下：

| 表面语法 | 含义 |
| --- | --- |
| `T?` | 可选值 |
| `T^` | owning pointer |
| `T&` / `T&!` | shared reference / 唯一可变引用 |
| `T*` / `T*!` | 只读 / 可写 raw pointer |
| `T[N]` | 定长数组 |
| `T[N:S]` | 带哨兵值 `S` 的定长数组 |
| `T[]` | 不定长数组类型 |
| `T[]&` | borrowed slice |
| `T[]^` | owning slice |
| `T[:S]&` | 借用哨兵 slice reference |

声明、`extend` target 和 `@where` type pattern 都应使用这些表面语法。用户自定义的 `Option`、
`Result`、`Ref`、`Box` 或 `Slice` 只是普通名义类型，不会获得内建语义。

类型级 `!` 只允许用于 `T&!` 和 `T*!`。`Int!`、`T^!`、`T[]!`、`T?!`、`T!&` 都是非法
类型。变量、参数、全局和字段是否可重新赋值，统一在绑定名后写 `!`。

## 类型推导

`_` 是右侧表达式类型的占位符。编译器会推导初始化表达式的自然类型；如果新绑定需要
重新赋值，把 `!` 写在新名字后面：

```c
_ answer = 42;
_ name = "Jiang";
_ values = [1, 2, 3];
```

下面这些声明形式把类型推导与绑定可变性分开表达：

| 绑定形式 | 含义 |
| --- | --- |
| `_ name` | 使用 RHS 类型创建不可变值绑定 |
| `_ name!` | 使用 RHS 类型创建可变值绑定 |

如果新绑定本身需要重新赋值，把 `!` 写在名字后：

```c
_ count! = 0;
count = count + 1;
```

类型推导会保留表达式的自然所有权和引用形态，不会为了推导局部变量自动解引用 `T^` 或 `T&`：

```c
Int^ make_value();

_ owner = make_value(); // owner: Int^
Int copied = make_value()$.get();
```

绑定可变性不属于值类型，因此从可变绑定复制值时，新绑定不会自动变成可变：

```c
Int source! = 1;
_ copied = source;   // 不可变绑定，值类型是 Int
_ mutable! = source; // 可变绑定，值类型是 Int
```

普通变量定义不能在左侧使用 `ref`。引用值应在右侧显式创建：

```c
Int value = 1;
Int& borrowed = value$.ref();
Int copied = borrowed$.get();

Int mutable_value! = 2;
Int&! mutable_ref = mutable_value$.mut_ref();
```

在解构和 pattern 中，`ref` / `ref!` 分别选择 shared / unique mutable borrow；
名字后的 `!` 只让新绑定可重新赋值：

```c
Int first! = 1;
Int second! = 2;
(ref! current) = first;
(ref! rebindable!) = second;
```

`ref` 后的类型位可以省略：`ref name` 等价于 `ref _ name`，`ref! name` 等价于
`ref! _ name`。这条规则同时适用于解构、承载值模式和 lambda capture：

```c
(ref left, _ right!) = pair;

if maybe is .some(ref item) {
    use(item);
}
```

type pattern 还可以只推导局部形状，例如 `Int[_] values` 或 `_[3] values`。

解构出的每个绑定和结构体的每个字段都在自己的名字后声明 `!`；可变性不会从外层类型自动传播。

## 绑定可变性

绑定名后的 `!` 表示这个存储位置可以被重新赋值。它是绑定元数据，不属于槽位中存放的类型：

```c
Bool flag! = true; // 可变绑定，槽位中存放 Bool
flag = false;

Int[3] values! = [1, 2, 3]; // 可写 array binding
values[0] = 10;
values = [4, 5, 6];
```

绑定可变性不进入函数签名。`foo(Int value!)` 与 `foo(Int value)` 的参数类型相同；前者只允许
函数体重新赋值参数槽。`foo(Int&! value)` 则要求唯一可变引用，这项能力属于类型并进入签名。

语言没有 `unique` 修饰符；`unique` 是普通标识符，唯一可变能力完全由 `T&!` 表达。

对于聚合值，成员只在外层访问 place 和成员声明都提供写能力时才可写。
readonly outer view 会递归冻结所有可达字段。

```c
struct User {
    Int id;
    Int age!;
}

User user! = User(id: 1, age: 18)
user.age = 19; // 允许
// user.id = 2; // 编译错误

User& readonly = user$.ref();
// readonly.age = 20; // 编译错误：shared outer borrow 冻结字段
```

绑定名后的 `!` 不参与值类型的兼容性判断。`T&!` 与 `T*!` 的能力则属于类型，传参和
`return` 时不会被忽略。

## 数组和切片

数组长度是类型的一部分：

```c
Int[3] values = [1, 2, 3];
Int[_] inferred = [1, 2, 3];
```

嵌套数组通过继续添加后缀表达：

```c
Int[2][3] matrix = [[1, 2], [3, 4], [5, 6]];
```

`T[]` 表示长度在运行时确定的不定长数组类型。裸 `T[]` 不能作为普通值
单独存放或传递。需要运行时长度的借用切片引用时，使用 `T[]&`：

```c
Int[_] values = [1, 2, 3];
Int[]& view = values[..];
```

`T[]^` 是拥有所有权的不定长数组 handle；它拥有已初始化 buffer，
drop 时会析构元素并释放 allocation。

`T[:S]` 表示带哨兵值的不定长数组类型。`T[:S]&` 这类带哨兵值的切片视图额外携带类型层面的哨兵值保证。非字面量哨兵切片
不会在赋值给 `T[]&` 时隐式丢掉这个保证；需要普通切片视图时，写成 `value.slice()`
或 `value$.as(T[]&)`。

## 指针和引用

指针和引用分成几类：

- `T^`：owning pointer。
- `T&` / `T&!`：shared readonly / unique mutable non-owning reference。
- `T*` / `T*!`：只读 / 可写 raw pointer。

```c
Int^ owner = new Int(42);
Int value = owner$.get();
unsafe {
    owner$.dealloc();
}
```

expected type 为 `T` 时，`T^` 可以自动解引用；`$.get()` 用于显式读取 pointee。
`T&` 和 `T*` 需要显式读取。成员访问可以自动穿过 `T^`：

```c
Int value = 41;
Int& ref = value$.ref();
Int copied = ref$.get();

struct Box {
    Int value;
}

Box^ box = new Box(value: 42);
Int n = box.value;
```

## 可选类型

`T?` 表示值可能为 `null`：

```c
Int? maybe = 42;
Int? none = null;
```

字段访问可以使用可选链：

```c
_ field = user?.name;
```

`??` 用于提供默认值：

```c
Int value = maybe ?? 0;
```

`.some(...)` 用于解包：

```c
if maybe is .some(value) {
    return value;
} else {
    return 0;
}
```

## 可错返回

`T@E` 用于函数、方法和函数类型的返回位，表示函数成功时产生 `T`，失败时产生 `E`：

```c
enum Err {
    bad = 1,
}

Int@Err ok() {
    return 42;
}

Int main() {
    return try ok() catch { 0 };
}
```

可错值不会隐式变成 `T`。需要成功值时，要么在同错误类型的 `T@E` 函数中让错误传播，
要么使用 `try expr catch { ... }` 显式处理错误分支。

## 数值转换

数值字面量在定型前可以由上下文决定类型。已经定型的数值之间不做隐式提升：

```c
Float f = 0.5;
Float a = 2 + f; // 2 是字面量，可按 Float 参与表达式

Int two = 2;
// Float b = two + f; // 编译错误：Int 变量不会隐式提升为 Float
Float b = Float(two) + f;
```

安全转换使用目标类型初始化形式，例如 `Float(two)`、`Int(f)`。普通代码不要用 `value$.as(Type)`
表示日常转换；`$.as` 是低层强制转换，主要用于裸指针、整数地址、外部函数接口或其他能力受控的底层场景。
