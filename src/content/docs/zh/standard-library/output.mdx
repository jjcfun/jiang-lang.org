`print(value)` 向标准输出写入一个值，末尾添加换行，返回 `Void`。
无需 import 即可使用；导入 `std` 后，也可以写成 `std.print` 或 `std.io.print`。

```c
Int main() {
    print("Hello, Jiang!");
    print(42);
    print(true);
    Int left = 10;
    Int right = 20;
    print("\(left)_\(right)");
    return 0;
}
```

每次调用只接受一个参数。多个值可以通过[字符串插值](/zh/standard-library/text/#字符串插值)组合。
当前没有 separator 或 terminator 参数。

## 支持的类型

- UTF-8 字节切片（`UInt8[]&`），包括字符串字面量。
- owned `String` 或借用的 `String&`：前者会被消费，后者保留原值。
- `Bool`、各种宽度的有符号与无符号整数，以及 `Float16`、`Float32`、`Float64`。
- 实现了 `Formattable` 的自定义类型的借用值。

浮点数沿用 `StringBuilder` 默认的六位小数格式。
如果还要继续使用已有字符串，借用它：

```c
String text = "hello";
print(text$.ref());
print(text$.ref());
```

## 自定义格式

实现 `Formattable`，向可写的 builder 追加文本：

```c
struct User: Formattable {
    Int id;

    public Void format(self, StringBuilder&! out) {
        out.append("User(id: ");
        out.append(self.id);
        out.append(")");
    }
}

Int main() {
    User user = User(id = 42);
    print(user$.ref());
    return 0;
}
```

借用打印不会消费原值。`print` 使用 `Formattable`；字符串插值使用 `StringBuilder.append`
的重载，不会自动调用 `Formattable.format`。

## UTF-8 与输出错误

`String` 始终保存合法 UTF-8。打印字节切片时，无效序列会替换为 U+FFFD（`�`）。
需要严格校验输入时，使用 `String.from_utf8(bytes)`，通过可恢复的 `Utf8Error` 处理无效编码。

`print` 写入标准输出失败时会 panic。需要恢复错误、输出原始字节或不换行时，使用 `std.io.stdout()`：

```c
import std;

Int main() {
    std.fs.File output! = std.io.stdout();
    Void written = try output.write_all("hello") catch { return 1; };
    return 0;
}
```
