每个 Jiang 可执行程序都从 `main` 开始，它的整数返回值会成为进程退出状态。

```c
Int main() {
    print("Hello, Jiang!");
    return 0;
}
```

编译并运行：

```bash
jiang -o hello hello.jiang
./hello
echo $?
```

程序输出 `Hello, Jiang!` 和换行，退出状态为 `0`。
`print` 无需 import 即可使用；支持的类型见[标准输出](/zh/standard-library/output/)。

需要明确处理错误的 byte 输出时，使用 `std.io.stdout()`：

```c
import std;

Int main() {
    std.fs.File output! = std.io.stdout();
    Void written = try output.write_all("Hello, Jiang!\n") catch { return 1; };
    return 0;
}
```

## 一个小函数

```c
Int add(Int a, Int b) {
    return a + b;
}

Int main() {
    return add(40, 2);
}
```

函数最后一个表达式可以直接作为返回值，不一定要显式写 `return`。
