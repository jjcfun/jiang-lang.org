Jiang 0.4.9 提供 macOS arm64 预构建编译器包。现阶段推荐用发布包体验语言。

## 环境要求

- macOS arm64。
- 宿主系统中可用的 `cc`，用于最终链接可执行文件。

发布包中的编译器已经静态链接 Jiang 使用的 LLVM 库；运行发布包不需要单独安装
`libLLVM.dylib`。

## 安装发布包

从 [0.4.9 GitHub 发布页](https://github.com/jjcfun/jiang/releases/tag/0.4.9) 下载
`jiang-0.4.9-macos-arm64.zip`，然后解压。

安装 Jiang：

```bash
./install.sh
```

默认安装到：

```text
~/.jiang/versions/0.4.9
~/.jiang/bin/jiangc
```

如果需要，把 Jiang 加入 shell 的 PATH：

```bash
export PATH="$HOME/.jiang/bin:$PATH"
```

## 验证

检查编译器和 LLVM 运行时：

```bash
jiangc --version
```

第一行应该是：

```text
jiang 0.4.9
```

## 从源码构建

源码构建主要用于编译器开发。先克隆仓库：

```bash
git clone https://github.com/jjcfun/jiang.git
cd jiang
```

安装 LLVM：

```bash
bash ./script/install_llvm.sh
```

脚本会把 Jiang 托管的 LLVM 22 工具链安装到
`$JIANG_HOME/toolchains/llvm/<version>/<host>`。未设置 `JIANG_HOME` 时使用 `~/.jiang`。

使用已安装的 0.4.9 发布版构建并验证编译器：

```bash
BOOTSTRAP_RELEASE_VERSION=0.4.9 \
BOOTSTRAP_BIN="$HOME/.jiang/versions/0.4.9/bin/jiangc" \
BOOTSTRAP_DEPTH=stable \
VERIFY=full \
bash ./script/build_next.sh
```
