Jiang 为 macOS arm64 和 Linux x86_64 提供预构建编译器包。

## 环境要求

- macOS arm64 或 Linux x86_64。
- 宿主系统中可用的 `cc`，用于最终链接可执行文件。

发布包中的编译器已经静态链接 Jiang 使用的 LLVM 库；运行发布包不需要单独安装
LLVM 动态库。Linux 发布包要求 glibc 2.34 或更新版本。

## 一键安装

安装脚本会自动选择当前平台的发布包、校验 checksum，并配置 shell 的 PATH：

```bash
curl -fsSL https://github.com/jjcfun/jiang/releases/latest/download/install.sh | bash && . "$HOME/.jiang/env"
```

macOS 缺少 C 工具链时运行 `xcode-select --install`；Ubuntu 或 Debian 使用
`sudo apt install build-essential`。

## 手动安装发布包

从[最新 GitHub 发布页](https://github.com/jjcfun/jiang/releases/latest)下载当前 host 对应的归档，然后解压。

安装 Jiang：

```bash
./install.sh
```

默认安装到：

```text
~/.jiang/versions/<version>
~/.jiang/bin/jiang
~/.jiang/bin/jiangc  # 兼容链接
```

如果需要，把 Jiang 加入 shell 的 PATH：

```bash
export PATH="$HOME/.jiang/bin:$PATH"
```

## 验证

检查编译器和 LLVM 运行时：

```bash
jiang --version
```

第一行应该是：

```text
jiang <version>
```
