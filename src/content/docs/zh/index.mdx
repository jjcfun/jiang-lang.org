Jiang 是一门正在开发中的系统编程语言。自定义语法是 Jiang 实现 All in one 的基石：
用户可以基于自己的理想语法扩展语言，同时继续享受 Jiang 自带的类型检查和系统级运行效率。
Jiang 0.5.1 为 macOS arm64 和 Linux x86_64 提供发布版编译器包。

这份文档优先作为教程和使用指南来写。语言指南跟随当前开发版编译器；
安装与平台页面会说明正式支持的 release host 和工具链边界。

Jiang 0.5.1 加入 Linux x86_64 hosted 支持、增量编译与并行编译。本版本不包含 Linux no-libc
或 LSP；compiler service 基础保留给后续工具链复用。

## 项目状态

Jiang 语言编译器已经完成初步稳定自举：发布版编译器由 Jiang 源码生成，并通过完整语言测试验证。
0.5.1 的重点是 Linux hosted/libc、增量编译与并行编译。
其中 `#asm` 主要面向运行时、系统调用和平台边界代码，普通应用代码通常不需要直接使用。

现阶段可以把官网文档视为持续更新的语言指南，而不是完全冻结的规范。相对稳定的内容包括命名风格、
类型写法、绑定可变性、数组、指针、可选类型、导入规则、包规则和当前编译器命令行工作流。
