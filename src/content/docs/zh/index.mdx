Jiang 是一门正在开发中的系统编程语言。自定义语法是 Jiang 实现 All in one 的基石：
用户可以基于自己的理想语法扩展语言，同时继续享受 Jiang 自带的类型检查和系统级运行效率。
Jiang 为 macOS arm64 和 Linux x86_64 提供发布版编译器包。

这份文档作为教程和使用指南来写。从[安装](/zh/install/)开始，也可以配置
[VS Code](/zh/compiler/editor/)，使用诊断、补全与代码跳转。

Linux hosted 程序使用系统 libc 与本机工具链。

## 一键安装

在 macOS Apple Silicon 或 Linux x86_64 的终端粘贴以下命令：

```bash
curl -fsSL https://github.com/jjcfun/jiang/releases/latest/download/install.sh | bash && . "$HOME/.jiang/env"
```

安装脚本会自动下载 Jiang、校验 SHA-256，并配置 Bash 或 Zsh 的 PATH。
环境要求和手动安装方式见[安装指南](/zh/install/)。

## 项目状态

Jiang 语言编译器已经完成初步稳定自举：发布版编译器由 Jiang 源码生成，并通过完整语言测试验证。
`#asm` 主要面向运行时、系统调用和平台边界代码，普通应用代码通常不需要直接使用。

现阶段可以把官网文档视为持续更新的语言指南，而不是完全冻结的规范。相对稳定的内容包括命名风格、
类型写法、绑定可变性、数组、指针、可选类型、导入规则、包规则和当前编译器命令行工作流。
