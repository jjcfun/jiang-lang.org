---
title: 编译器命令行
description: Jiang 编译器命令行接口。
---

`jiang` 用于编译 Jiang 源文件。当前编译器可以生成 LLVM IR、目标文件，也可以通过宿主 C 编译器链接出可执行文件。
发布包继续提供 `jiangc` 兼容链接供已有脚本使用；新命令应使用 `jiang`。

## 版本和帮助

```bash
jiang --version
jiang --help
```

`--version` 会打印 Jiang 编译器版本、宿主 target 和 LLVM 版本。

## 只检查

```bash
jiang --check tests/samples/minimal.jiang
```

这个模式会完成解析、名字解析和类型检查，但不会生成 LLVM IR、目标文件或可执行文件。

## 生成 LLVM IR

```bash
jiang --emit-llvm tests/samples/minimal.jiang
```

默认情况下，LLVM IR 会输出到标准输出。使用 `-o` 可以写入文件：

```bash
jiang --emit-llvm tests/samples/minimal.jiang -o minimal.ll
```

## 生成目标文件

```bash
jiang --emit-obj tests/samples/minimal.jiang -o minimal.o
```

这个模式会停在目标文件生成阶段，不会继续链接可执行文件。

## 链接可执行文件

不指定 `--emit-*` 时，`jiang` 会生成临时目标文件，并调用宿主 `cc` 链接可执行文件：

```bash
jiang tests/samples/minimal.jiang -o minimal
```

然后运行：

```bash
./minimal
echo $?
```

## 调试和发布模式

`jiang` 默认使用调试模式：

```bash
jiang --mode debug main.jiang -o main
```

发布模式会启用 LLVM 优化：

```bash
jiang --mode release . -o app
```

需要限制编译并发度时，使用 `--jobs`：

```bash
jiang --jobs 1 . -o app
```

## 目标平台

生成 LLVM IR 或 object 时可以使用 `--target`：

```bash
jiang --target x86_64-unknown-linux-gnu --emit-obj main.jiang -o main.o
```

hosted executable 只使用目标平台的本机工具链链接。发布包支持 macOS arm64 和 Linux x86_64；
Linux hosted 程序使用系统 libc。Linux aarch64、Wasm、WASI 和 Windows 目前只有较窄或实验性的
输出边界；Linux no-libc executable 尚不可用。

## 链接器选项

使用 `--linker` 指定最终链接程序：

```bash
jiang --linker /usr/bin/cc main.jiang -o main
```

使用可重复的 `--link-arg` 传递额外链接参数：

```bash
jiang main.jiang -o main --link-arg -lm
```

## 运行时边界

hosted 构建使用目标 host 的 C runtime 与本机 linker toolchain。发布版编译器已经包含 `jiang`
使用的 LLVM 库，因此运行发布包不需要另外安装 `libLLVM` 或 `liblld`。
