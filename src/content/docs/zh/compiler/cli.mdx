---
title: 编译器命令行
description: Jiang 编译器命令行接口。
---

`jiangc` 用于编译 Jiang 源文件。当前编译器可以生成 LLVM IR、目标文件，也可以通过宿主 C 编译器链接出可执行文件。

## 版本和帮助

```bash
jiangc --version
jiangc --help
```

`--version` 会打印 Jiang 编译器版本、宿主 target 和 LLVM 版本。

## 只检查

```bash
jiangc --check tests/samples/minimal.jiang
```

这个模式会完成解析、名字解析和类型检查，但不会生成 LLVM IR、目标文件或可执行文件。

## 生成 LLVM IR

```bash
jiangc --emit-llvm tests/samples/minimal.jiang
```

默认情况下，LLVM IR 会输出到标准输出。使用 `-o` 可以写入文件：

```bash
jiangc --emit-llvm tests/samples/minimal.jiang -o minimal.ll
```

## 生成目标文件

```bash
jiangc --emit-obj tests/samples/minimal.jiang -o minimal.o
```

这个模式会停在目标文件生成阶段，不会继续链接可执行文件。

## 链接可执行文件

不指定 `--emit-*` 时，`jiangc` 会生成临时目标文件，并调用宿主 `cc` 链接可执行文件：

```bash
jiangc tests/samples/minimal.jiang -o minimal
```

然后运行：

```bash
./minimal
echo $?
```

## 调试和发布模式

`jiangc` 默认使用调试模式：

```bash
jiangc --mode debug main.jiang -o main
```

发布模式会启用 LLVM 优化；当输入是包目录时，发布模式会按包组织目标文件：

```bash
jiangc --mode release . -o app
```

如果输入是单个源文件，发布模式仍然直接编译这个源文件。

## Artifact cache 与 backend jobs

debug 包构建默认把可复用的源码 interface 与 object work product 持久化到 `build/cache`。
需要隔离不同构建时，可以覆盖 cache 位置：

```bash
jiangc --artifact-cache-dir .jiang-cache . -o app
```

脚本需要清理 cache 时，使用显式命令，不要删除一个尚未解析确认的路径：

```bash
jiangc --artifact-cache-dir .jiang-cache --clean-artifact-cache
```

互相独立的 debug codegen unit 可以并发执行。默认 worker 数量是当前进程可用的逻辑 CPU 数；
只有需要明确限制时才传 `--jobs`：

```bash
jiangc --jobs 1 . -o app
```

`--jobs` 当前只影响 debug 包的 object emission。release、shared library、LLVM IR 和单 object
输出仍为串行路径。某个 unit 失败不会删除其他成功 unit 的缓存 object，
后续构建仍可复用。

## 目标平台

生成 LLVM IR 或 object 时可以使用 `--target`：

```bash
jiangc --target x86_64-unknown-linux-gnu --emit-obj main.jiang -o main.o
```

hosted executable 只使用目标平台的本机工具链链接。Jiang 0.5.1 支持 macOS arm64 和
Linux x86_64 release host；Linux hosted 程序使用系统 libc。Linux aarch64、Wasm、WASI 和
Windows 目前只有较窄或实验性的输出边界；Linux no-libc executable 不属于 0.5.1。

## 链接器选项

使用 `--linker` 指定最终链接程序：

```bash
jiangc --linker /usr/bin/cc main.jiang -o main
```

使用可重复的 `--link-arg` 传递额外链接参数：

```bash
jiangc main.jiang -o main --link-arg -lm
```

## 运行时边界

hosted 构建使用目标 host 的 C runtime 与本机 linker toolchain。发布版编译器已经包含 `jiangc`
使用的 LLVM 库，因此运行发布包不需要另外安装 `libLLVM` 或 `liblld`。
