Jiang provides prebuilt compiler packages for macOS arm64 and Linux x86_64.

## Requirements

- macOS on arm64 or Linux on x86_64.
- A host C compiler available as `cc` for final executable linking.

The release compiler statically links the LLVM libraries used by Jiang. You do not need a separate
LLVM shared-library installation to run the packaged compiler. The Linux package requires glibc 2.34
or newer.

## Quick Install

The installer selects the package for your platform, verifies its checksum, and sets up the shell path:

```bash
curl -fsSL https://github.com/jjcfun/jiang/releases/latest/download/install.sh | bash && . "$HOME/.jiang/env"
```

On macOS, install the C toolchain with `xcode-select --install` if needed. On Ubuntu or Debian, use
`sudo apt install build-essential`.

## Install an Archive

Download the archive for your host from the [latest GitHub release](https://github.com/jjcfun/jiang/releases/latest), then unpack it.

Install Jiang:

```bash
./install.sh
```

By default this installs:

```text
~/.jiang/versions/<version>
~/.jiang/bin/jiang
~/.jiang/bin/jiangc  # compatibility link
```

Add Jiang to your shell path if needed:

```bash
export PATH="$HOME/.jiang/bin:$PATH"
```

## Verify

Check the compiler and LLVM runtime:

```bash
jiang --version
```

The first line should be:

```text
jiang <version>
```
