Jiang 0.5.1 provides prebuilt compiler packages for macOS arm64 and Linux x86_64.

## Requirements

- macOS on arm64 or Linux on x86_64.
- A host C compiler available as `cc` for final executable linking.

The release compiler statically links the LLVM libraries used by Jiang. You do not need a separate
LLVM shared-library installation to run the packaged compiler. The Linux package requires glibc 2.34
or newer.

## Install a Release

Download `jiang-0.5.1-macos-arm64.zip` or `jiang-0.5.1-linux-x86_64.tar.gz` from the
[0.5.1 GitHub release](https://github.com/jjcfun/jiang/releases/tag/0.5.1), then unpack it.

Install Jiang:

```bash
./install.sh
```

By default this installs:

```text
~/.jiang/versions/0.5.1
~/.jiang/bin/jiangc
```

Add Jiang to your shell path if needed:

```bash
export PATH="$HOME/.jiang/bin:$PATH"
```

## Verify

Check the compiler and LLVM runtime:

```bash
jiangc --version
```

The first line should be:

```text
jiang 0.5.1
```

## Build From Source

Source builds are mainly for compiler development. Clone the repository:

```bash
git clone https://github.com/jjcfun/jiang.git
cd jiang
```

Install the pinned LLVM 22.1.8 SDK. Use `--user` to keep one verified SDK under `~/.jiang` and share
it across worktrees:

```bash
bash ./script/install_llvm.sh --user
```

The script downloads a checksum-locked Jiang LLVM SDK for macOS arm64 or Linux x86_64 and installs it
under `$JIANG_HOME/toolchains/llvm/<version>/<host>`. If `JIANG_HOME` is not set, `~/.jiang` is used.
It does not use an arbitrary system or Homebrew LLVM. Omit `--user` to install a worktree-local SDK
under `build/llvm/<host>/install` instead.

Build and verify the compiler with the installed 0.5.1 release:

```bash
BOOTSTRAP_RELEASE_VERSION=0.5.1 \
BOOTSTRAP_BIN="$HOME/.jiang/versions/0.5.1/bin/jiangc" \
BOOTSTRAP_DEPTH=stable \
VERIFY=full \
bash ./script/build_next.sh
```
